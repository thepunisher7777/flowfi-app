# Ledger by ARX — actualización de branding

Paquete preparado para subir a GitHub Pages sin perder los datos locales existentes.

## Qué cambia
- Nombre principal de la app: **Ledger**
- Marca secundaria / marca de agua: **Ledger by ARX**
- Texto central del círculo de categorías: **LEDGER**
- Iconos PWA actualizados con el icono de **ARX**
- `manifest.webmanifest` añadido para instalación correcta en iPhone y Android

## Importante
- **No cambia la clave local de almacenamiento**, así que la actualización mantiene los datos guardados en los navegadores/dispositivos que ya usan la app.
- Solo tienes que sustituir en GitHub los archivos por los de este paquete.
